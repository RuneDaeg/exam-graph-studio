# 도해 — 시험지 그래프 스튜디오

한국어 설명과 문제집 그래프 이미지에서 편집 가능한 흑백 시험지 그래프를 만드는 웹앱입니다. GitHub Pages에서 동작하는 정적 React 앱입니다.

## 사용 방법

1. **내 API 연결**에서 본인의 OpenAI API 키를 입력합니다.
2. 그래프를 설명하거나 PNG/JPG/WebP 이미지를 첨부합니다.
3. 생성한 그래프의 좌표·축·눈금·문자를 확인하고 수정합니다.
4. SVG 또는 PNG로 다운로드합니다.

기본 예시 10개와 기출 대표 유형 28개, 직접 좌표 입력, 편집 및 다운로드는 API 키 없이 사용할 수 있습니다.

**기출 유형 둘러보기**에서 과목을 고르거나 유형·개념·연도를 검색한 뒤, 출처와 변경 내용을 확인하고 **이 그래프로 시작**을 누르세요. 2022–2026년 시행 과학탐구Ⅰ·Ⅱ 6·9월 모의평가에서 선별한 20개 유형과, 2022–2025년 고1 통합과학 전국연합학력평가에서 선별한 8개 유형을 새 좌표로 재구성했습니다. 전체 그래프의 개수를 집계한 목록은 아닙니다. [과학탐구 출처](docs/exam-library-sources.md)와 [통합과학 출처·검토 범위](docs/integrated-science-sources.md)에서 원문 문항을 확인할 수 있습니다.

## API 키와 비용

- 사용자가 입력한 키와 설명·이미지는 브라우저에서 `https://api.openai.com/v1/responses`로 직접 전송됩니다.
- 키는 현재 탭의 메모리에만 보관하며 localStorage, sessionStorage, 쿠키, URL, 서버에 저장하지 않습니다. 새로고침 또는 연결 해제 시 지워집니다.
- 사용 비용은 입력한 키의 OpenAI 계정에 청구됩니다. ChatGPT 구독과 API 과금은 별개입니다.
- 브라우저의 페이지 스크립트·확장 프로그램은 키에 접근할 수 있습니다. 신뢰하는 개인 기기에서 사용하며 앱 전용 키를 권장합니다.
- GitHub 저장소·Pages 빌드·Actions에는 OpenAI 키를 설정하지 않습니다. 모델은 `gpt-5.4-mini`입니다.

## 그래프 편집

- 기본 과학 그래프 10개와 과학탐구Ⅰ·Ⅱ·통합과학 기출 대표 유형 28개, 과목 필터·검색·출처 확인
- AI 없이 좌표 입력
- 미리보기에서 점·선·문자 드래그, 축 이름·눈금 클릭 편집
- **직접 편집**에서 점·선·문자·보조선·눈금을 선택한 뒤 **Delete / Backspace** 또는 선택 창의 삭제 버튼으로 삭제. 축 이름은 글자만 삭제하며, 분포 봉우리·원/타원 손잡이는 해당 그래프 전체를 삭제. 삭제마다 실행 취소로 복원할 수 있고, 글자 입력 중에는 그래프 요소를 삭제하지 않음
- **점 추가**를 켜고 선 위를 클릭하면 기존 점 사이에 삽입; 점·선 선택 후 구간을 골라 중간에 추가할 수도 있음
- **음영 추가**로 선과 기준선 사이, 두 선 사이, 닫힌 선 내부를 회색 또는 빗금으로 채우기; x 구간·진하기 조절
- **사각형 음영**을 켜고 대각선으로 드래그하면 선과 독립적인 구역 음영 생성; 음영 편집에서 x·y 시작/끝, 회색·빗금, 진하기 조절 (축 범위 안에 표시)
- 추가한 점과 음영은 실행 취소·다시 실행 및 SVG·PNG 다운로드에 반영
- 점이나 선을 선택해 각 선의 연결 방식을 **직선 / 매끄러운 곡선**으로 전환 (좌표 유지)
- 각 선에 **실선 / 파선 / 점선 / 일점쇄선 / 이점쇄선**을 선택; 미리보기·세부 편집·SVG·PNG에서 같은 패턴 사용
- 매끄러운 곡선은 3개 이상의 점을 순서대로 연결하며, 닫힌 곡선과 x 방향이 되돌아오는 경로도 지원 (다각형·꺾은선은 직선 연결 유지)
- 원·타원은 중심과 반지름의 수식으로 그리며, **원·타원 공식 적용**으로 기존 닫힌 선을 변환 가능; 네 방향 손잡이로 크기, 선 드래그로 중심 조절
- **축·눈금 → 가로·세로 같은 축척**으로 두 축의 단위 길이를 일치시킴; 원·타원 생성 시 기본 적용되어 원이 타원처럼 찌그러지지 않음
- 형질 분포 예시는 `x^a e^(-bx)` 계열의 감마형 공식으로 계산: 봉우리 드래그로 위치·높이를 바꾸고, **분포 공식**에서 모양 지수로 폭·비대칭을 조절
- 기존 선에도 **분포 공식 적용** 가능; **자유 곡선으로 전환**하면 개별 점 편집·추가 및 직선/곡선 연결을 다시 사용 (감마형은 오른쪽 꼬리가 긴 분포의 예시이며, 모든 형질의 분포 법칙을 뜻하지 않음)
- 좌표 맞춤, 방향키 미세 이동, 드래그 1회 단위 실행 취소
- **보조선·문자 함께 이동**은 기본 켜짐: 점·봉우리 드래그, 방향키, 수치 입력으로 바꿀 때 연결된 보조선과 문자가 함께 이동 (가로·세로 투영선의 축 쪽 끝은 축에 유지). 필요하면 끌 수 있음
- **정규분포** 예제와 분포 종류 선택: 평균 μ·표준편차 σ·높이를 조절하고, 연결 옵션을 켜면 μ·μ±σ 기호 눈금도 함께 이동. 확률밀도 높이 버튼은 현재 σ에 맞춰 높이를 1/(σ√(2π)), 기준 높이를 0으로 설정
- 미리보기에 이미지 끌어놓기
- 축 범위·눈금·곡선·점·진행 화살표·문자·점선 편집
- **좌표·축·눈금·문자 편집 → 축·눈금 → 오른쪽 세로축 사용**으로 다른 변인의 축 추가: 독립적인 이름·단위·범위·눈금을 설정하고 곡선별 기준 축을 선택. 기본 예시 **기온 · 상대 습도**에서도 시작 가능 (가상 자료)
- 오른쪽 축에 연결된 점·선의 드래그와 보조선·문자·음영도 해당 축 단위를 사용. 기준 축을 바꾸면 좌표 숫자는 유지되므로 새 단위에 맞게 확인. 서로 다른 축의 두 선 사이 음영과 이중축의 가로·세로 같은 축척은 지원하지 않음
- 그래프 한글 글꼴: 명조·고딕·돋움 선택. 한글과 수식이 섞인 축 이름에도 적용되며 수식·숫자는 KaTeX 유지. 돋움 미설치 기기에서는 유사한 고딕 글꼴 사용
- KaTeX 수식: 숫자, 변수, 첨자, 단위, 분수, 근호
- KaTeX 글꼴을 SVG path로 변환하여 SVG와 1–4배 PNG에서 같은 수식 모양 유지
- 투명 배경, 선 두께·글자 크기, 실행 취소·다시 실행

이미지에 없는 수치는 상대 좌표로 복원될 수 있습니다. 문항에 사용하기 전 수치와 기호를 확인해 주세요. 한글은 기기 글꼴에 따라 달라질 수 있습니다.

## 로컬 실행과 배포

Node 22.13 이상이 필요합니다.

```sh
npm ci
npm run build:pages
npm run preview:pages
```

기본 경로는 `/exam-graph-studio/`입니다. 다른 저장소에는 `PAGES_BASE_PATH=/저장소이름/ npm run build:pages`, 계정 루트 사이트에는 `PAGES_BASE_PATH=/ npm run build:pages`를 사용합니다.

GitHub 저장소 Settings → Pages → Source를 **GitHub Actions**로 선택하면, `main`에 push할 때 `.github/workflows/pages.yml`이 `dist-pages`만 배포합니다. API 키 secret은 필요하지 않습니다.

이전 로컬 Sites 개발 환경은 `npm run dev`로 실행할 수 있습니다. 기존 서버용 `.env.local`과 `.wrangler`는 Git 및 Pages 빌드에서 제외됩니다. Pages는 서버 경로를 사용하지 않습니다.
