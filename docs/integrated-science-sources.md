# 통합과학 기출 그래프 검토 기록

검토일: 2026-10-08

## 범위와 방법

통합과학은 기존 과학탐구Ⅰ·Ⅱ 대표 20개와 별도로 **고1 전국연합학력평가 8회차의 공식 EBSi 문제지 PDF 36쪽을 텍스트 파싱**했습니다. 대상 회차는 2022년 9월·11월, 2023년 9월·11월(12월 시행), 2024년 9월·10월, 2025년 9월·10월입니다. 텍스트에서 그래프와 변인 관계의 후보를 찾은 다음, 후보 **7쪽을 이미지로 렌더링해 시각 검토**했습니다. 그중 **5회차·5쪽의 8문항에서 8개 편집용 예시**를 선정했습니다.

이는 해당 기간 전체 문제의 그래프 수를 센 결과가 아니며, 2022–2026년 5개년 전체 회차를 검토한 목록도 아닙니다. 2026년 통합과학 문제지는 이번 수록에 포함하지 않았습니다. 기존 20개 역시 전체 그래프 개수가 아니라 앞서 선택한 대표 유형 수입니다.

원문의 그래프를 스캔하거나 좌표를 복제하지 않았습니다. 유형을 확인한 후 별도의 수치·함수·상대 척도로 재구성했습니다. 특히 원문 축을 바꾸거나 운동 경로 그림을 좌표 그래프로 옮긴 경우를 각 항목의 `adaptation.note`에 표시했습니다. 원문 문항의 정답 계산 자료나 실제 측정 자료로 사용하면 안 됩니다.

9월 고1 시험의 출제 기관은 인천광역시교육청, 11월·10월 고1 시험은 경기도교육청입니다. 2023년 시험지 표제는 **11월**이고, 실제 시행일은 **12월 19일**입니다. 실제 시행일과 경기도교육청 주관 여부는 [EBS 공식 안내](https://about.ebs.co.kr/board/bbs?boardId=31&boardTypeId=1&cmd=view&postId=30002817866)로 확인했습니다. 2022년 9월 시험은 8월 31일 시행됐지만 EBS 파일 경로에는 `20220901`이 들어갑니다.

자연선택 예시는 정규분포 모형을 선택한 편집용 예시입니다. 원문 그래프가 정규분포를 따른다는 의미나 모든 형질이 정규분포를 따른다는 의미가 아닙니다. 개체 수준의 변형과 과학적 사실이 일치하지 않을 수 있다는 주의 문구를 해당 미리보기에 포함했습니다.

충격량 예시의 보간 곡선을 수치 검증한 면적은 두 선 모두 약 8.0008006 N·s로 같으며, 원래 함수의 정확한 값 8 N·s에 대한 오차는 약 0.01%입니다. SVG 좌표의 반올림 때문에 내보낸 두 면적에는 약 0.000009 N·s의 차이가 생길 수 있습니다.
