# 교과서 그래프 유형 라이브러리

19권의 과학 교과서 총 3,422쪽을 텍스트 탐색하고, 후보 중 77쪽의 그림을 검토한 분석에서 **대표 사례 88건**을 선정했다. 이는 교과서 전체 그래프의 개수나 전수 시각 검토 결과가 아니다. 여러 패널이 있는 사례를 분리하여 **115개 편집 패널**로 제공한다.

## 자료와 공개 범위

- 출처는 비상교육 교과서의 책 이름, PDF 쪽수, 책에 인쇄된 쪽수, 확인한 그림 번호로 기록한다. PDF 쪽수와 인쇄 쪽수는 별도 필드다.
- 공개 코드에는 원본 PDF, 페이지 이미지, 교과서 본문, OCR 텍스트, 로컬 파일 경로, 다운로드 링크를 포함하지 않는다.
- 그래프 좌표는 직접 구성한 합성값 또는 프리셋에 명시한 수식으로 생성한다. 원본 실측값을 디지타이징한 결과라고 표시하지 않는다.
- 출처 표시는 그래프 **유형을 확인한 위치**를 뜻한다. 편집 예시의 모든 수치를 그 출처에서 가져왔다는 뜻이 아니다.
- 실제 데이터가 필요한 출제에서는 검증된 원자료와 단위, 유효 숫자, 실험·모형의 가정을 따로 확인해야 한다.

## 구성

| 파일 | 역할 |
|---|---|
| `lib/textbook-data.ts` | 88개 사례의 서지 정보와 구조 설명 |
| `lib/textbook-presets.ts` | 독립 좌표·공식으로 만든 115개 그래프와 사례별 주의점 |
| `components/textbook-library.tsx` | 영역·책·검색어 필터, 목록 페이지, 패널 선택, 출처·주의점 표시 |
| `components/textbook-library.css` | 남색 테마에 맞춘 라이브러리 레이아웃 |
| `scripts/test-textbook-library.mjs` | 전 사례/패널의 스키마·렌더·과학 관계 검사 |

영역은 과학탐구실험, 통합과학, 물리학, 화학, 생명과학, 지구과학, 중학 과학의 7종이다. 책별로도 검색할 수 있다. 목록은 한 번에 16건만 표시하고, 선택한 패널 1개에만 KaTeX 미리보기를 생성한다. 불러올 때는 구조 복사하여 원본 프리셋이 편집에 의해 바뀌지 않게 한다.

## 정량 관계와 한계

전용 프리셋 중 일부는 물리 관계를 유지하도록 생성한다. 예를 들어 등가속도, 훅의 법칙, 옴의 법칙, 이상기체 관계, 1차 RL/RC 회로, Planck 흑체 분포, 3차원 이상기체의 운동 에너지 분포, 단순 효소 포화식, 이항 유전 모형을 사용한다. 나머지는 명시적으로 **개념도·상대 축·합성 표본**으로 제공한다.

- G013~G014: 운동 에너지 분포는 `sqrt(E) exp(-E/T) / T^(3/2)`로 생성한다. 속력 분포와 구분하고, 온도 간 전체 적분에 같은 배율을 사용한다. 표시 범위 바깥 꼬리는 잘린다.
- G025: 삼투압 = 팽압 + 흡수력을 생성 시점에 맞춘다.
- G035~G036: 충전/전류 모형과 에너지의 제곱 관계를 유지한다.
- G038: 제시 구간에서 확률 밀도 적분이 1인 사인 제곱 모형이다.
- G045: 온도마다 독립적으로 최대값을 정규화하지 않고 같은 배율의 Planck 식을 사용한다.
- G067: A와 B의 총량을 두 초기 조건에서 모두 일정하게 유지한다.
- G074: 두 물체의 열용량 비 1:2에 맞춰 에너지 보존과 공통 평형 온도를 유지한다.

자유 점 편집은 이러한 관계를 자동으로 보존하지 않는다. 미분·적분·평형·총량 등의 제약을 필요로 하는 문제라면 편집 후 다시 검산해야 한다. 정성 프리셋의 숫자를 원자료의 수치 답안으로 사용해서는 안 된다.

여러 패널은 각각 선택하여 불러온다. 한 도화지 안에 패널을 자동 배치하거나, 패널 사이의 축·파라미터를 동기화하는 기능은 제공하지 않는다. G066의 원래 3차원 주기율표 막대는 주기별 2차원 막대로 재구성했다. 원 궤도와 단진동(G034)도 독립 패널이며 자동 투영 연동은 없다. 일부 원문의 장식·사진·색 띠·등밀도선의 정확한 계산·곡선 방향의 물리 제약 등은 주의점에서 한계를 밝힌다.

## 검증

`node scripts/test-textbook-library.mjs`

88개 ID 및 19권의 출처 범위, 115개 패널 스키마, 좌표별 축 범위, 모든 SVG의 유한 값, 690개 수식 라벨의 KaTeX 파싱, 책·영역·검색어 필터, 프리셋 복사, 비공개 파일 경로 배제를 검사한다. 추가로 이항 빈도 합, 평형 총량, 삼투압 관계, 열평형 에너지, 인덕터 에너지, 촉매 경로의 공통 양끝 등의 관계를 검사한다. 이 검증은 교과서의 모든 그래프를 수치적으로 복제했다는 의미가 아니다.
